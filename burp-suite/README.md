# Burp Suite

Burp Suite was used to intercept, inspect, analyze, replay, and manually modify HTTP traffic for the authorized SecureLab web application.

## Testing Performed

### 1. HTTP History Analysis

Burp Suite Proxy HTTP History was used to observe HTTP requests generated by the SecureLab application.

Observed traffic was analyzed for:

- Main application requests
- Static resources
- HTTP methods
- Request and response headers
- Status codes
- Parameters
- Cookies and session information

#### Evidence

![Burp HTTP History](screenshots/01-burp-http-history.png)

---

### 2. Burp Repeater

Captured HTTP requests were sent to Burp Repeater for manual request modification and response analysis.

Burp Repeater was used to:

- Replay individual requests
- Modify HTTP requests
- Compare server responses
- Analyze application behavior
